Six categories, one prompt each

All prompts are drawn from VABench. Every pair uses the identical prompt on the identical backend — the only variable is whether Seedance 1 is called directly or through the agent policy.

PK · Procedural Knowledge #10520

Spinning a gossamer ballooning thread, a young spider gradually lifts off the ground and drifts on rising thermals.

MI · Multi-Entity Identity #12018

MS · Multi-Shot #5001

All twelve clips are the raw outputs — no post-processing, no cherry-picking within a run. Prompt IDs refer to the VABench 180-item eval split. For the corresponding Seedance 2 pairings and the agentic workflow visualisations, see the main page and workflow gallery.
