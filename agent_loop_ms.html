One prompt, two policies MS · #5125

How to read this frame. The full user prompt sits in the top banner, with the three second-anchored beats highlighted. Both baselines stay near the first beat — leaves in the gutter — and never reach the bracket break or the collapse. On the right, the agent parses the prompt into three phases, runs Seedance T2V for Phase 1, then chains extract_last_frame → Seedance I2V for Phase 2 and Phase 3, and finally concatenates the three clips into a single 12-second video.

This is the same case shown in the paper's teaser figure (MS row). For the other agent-loop demos — single-entity retrieval, multi-entity identity composition, physics simulation — see the main page and workflow gallery.
